# 变更和交付记录模板

共享约定改变时，同步改变文档、接口、实现调用方和验收，不用群聊口头决定替代仓库版本。当前契约为 0.2.0。新增可选字段可升小版本；删除、改名、类型或语义不兼容需要显式记录迁移与三方同步，不偷偷保留多个不同标准。

## 共同约定变更

```text
变更编号和日期：
提出人及任务：
现契约版本和建议版本：
问题及实际证据：
建议的最小改动：
影响的接口、调用方、数据迁移和测试：
需要同步的人员与实施顺序：
队长决定和对应提交：
```

当前初版建立需求、共享接口、金额口径、角色边界和任务依赖；OCR 提供方、模型名、实际服务器限制待真实验证后补充。初版不表示三名成员已经完成阅读或同意具体实现。
