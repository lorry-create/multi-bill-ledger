# 平台品牌图形来源

- 微信：https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg
- 支付宝：https://github.com/simple-icons/simple-icons/blob/develop/icons/alipay.svg
- 来源项目 Simple Icons，CC0；图形保持原有路径，使用微信绿色 `#07C160`、支付宝蓝色 `#1677FF`。
- 图形只用于标识账单来源，不表示平台官方合作或直接 API 接入。

归账品牌图形为本项目原创 SVG，两个来源汇入同一账本的方向构成品牌记号。
